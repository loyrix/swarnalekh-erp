# Plan — 26 July 2026

New set of 5 requirements. Analysed against code; owner decisions captured below.

## Order of work

1. Inventory: Total Products excludes sold
2. Mortgage: edit Close (reopen → edit → re-close)
3. Global date filters: full preset picker across modules
4. Tag import/export: CSV/Excel importer that preserves tags
5. Mortgage Top-up (own phase, last — biggest)

## 1. Inventory — Total Products count

- [x] `totalProducts` must count only available items (everything except `sold`).
      Today `inventory.service.ts` sets `totalProducts: items.length` (includes sold).
      Fix: count items where `status != 'sold'`. Sold stays in Sales History + Reports (already there).

## 2. Mortgage — Edit Collect & Close

Already done: edit-Collect on active loans (PATCH payment + recalc) and the audit log
(global AuditLogInterceptor records every mutation). Gap = editing **Close**.

- [ ] Add a "Reopen loan" action: flips a closed loan back to `active`, removes the
      closure payment, recomputes principal/interest/outstanding.
- [ ] After reopen, the owner corrects entries (existing edit flow), then closes again.
- [ ] Audit each step (reopen / edit / re-close) — interceptor already covers it.

## 3. Global Date Filters

Foundation exists (`StatPeriod`: today / month / 3-6-12 months / all / custom + selector;
server `resolveDateRange` mirrors it). Reports & Billing still use free-text date fields.

- [ ] Add presets: Today, Yesterday, Last 7 Days, Last 30 Days, This Month, Last Month,
      Last 3 Months, Last 6 Months, Financial Year, Custom Range.
- [ ] Extend server `resolveDateRange` with the new presets (yesterday, last7, last30,
      lastMonth, financialYear).
- [ ] One reusable Date Range Picker adopted across Inventory, Billing, Mortgage, Reports.

## 4. Tag Number & Migration (CSV/Excel import)

Already done: export has a Tag column; the OCR import preserves typed tags, auto-generates
only for new items, and 409s on duplicates. Gap = a generic file importer.

- [ ] CSV/Excel importer: upload a file exported from another jewellery ERP.
- [ ] Column mapping (Tag, Item, Category, Metal, Karat, Gross, Net, Qty, …).
- [ ] Preserve existing Tag Numbers exactly; generate tags only for rows without one.
- [ ] Validate duplicate Tag Numbers before saving (reject with a clear per-row error).
- [ ] Export keeps the same Tag Numbers unmodified (already true — verify round-trip).

## 5. Mortgage Top-up (own phase, last)

Net-new: no top-up field, endpoint, UI, or settings table anywhere today.

- [ ] Global Mortgage Setting to choose the top-up interest policy (needs a settings
      store — none exists yet).
- [ ] Option 1 (Merge): add top-up to the original loan, interest from the original date.
- [ ] Option 2 (Separate): top-up interest runs from its own transaction date.
- [ ] Business-logic support for both modes; top-up endpoint + UI.
