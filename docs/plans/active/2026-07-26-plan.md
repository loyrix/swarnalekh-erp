- [x] Audit each step (reopen / edit / re-close) — interceptor already covers it.

- [x] Column mapping (Tag, Item, Category, Metal, Karat, Gross, Net, Qty, Price, HUID)

- [x] Preserve existing Tag Numbers exactly; generate tags only for rows without one
